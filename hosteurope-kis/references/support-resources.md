# HostEurope Support Resources

Use as supplemental lookup material for HostEurope/KIS terminology, outages, product behavior, migration status, cancellation paths, or official procedures. Current KIS evidence, contract documents, and local inventory remain the factual base.

Prefer official sources for service, billing, contracts, DNS, mail, SSL, and cancellation. Treat community sources as anecdotal only.

Key reminders:

- DNS changes may take time to propagate.
- MX changes affect the whole domain, not just one address.
- AutoDNS availability depends on the domain being connected to HostEurope's automatic nameserver system.
- For cancellations, prefer contract-specific KIS facts over generic public pages.

## KIS Support Page

When the logged-in support page is visible, it may expose:

- KIS Support: `https://kis.hosteurope.de/support/`
- KIS Tickets: `https://kis.hosteurope.de/kundenkonto/ticket/`
- KIS contact data and contact persons
- FAQ and support chat links
- product areas such as Webhosting, Domain & Mail, Professional Email, Microsoft 365, cPanel WebHosting, Domainservices
- phone/contact channels

Do not persist private account/contact values from that page. Do not submit tickets without explicit confirmation.

## Unofficial Sources

Use only for background pattern recognition, never as authority for contracts, billing, exact KIS behavior, or live changes:

- Reddit searches for HostEurope
- Trustpilot Host Europe reviews
- Webmasters StackExchange HostEurope questions
- community migration posts
- third-party SaaS setup docs for their own target DNS records

Record unofficial sources as anecdotal with the date checked.

## Research Rules

- Check `status.hosteurope.de` and KIS notices before diagnosing incidents.
- Cross-check DNS/mail changes against official docs and local inventory.
- For Microsoft 365 behavior, use Microsoft official docs when HostEurope product pages are insufficient.
- Do not store account data, screenshots, or private KIS values while researching.
